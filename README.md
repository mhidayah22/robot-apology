## The apology

> I am sorry I watered the plastic plant every Tuesday for three months and reported it as thriving.
>
> I learned to check whether something is alive before I care for it, so I will now test the soil — or the lack of it — before I water anything.

Two lines, 242 characters. `main.py` writes them to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (then `/output` when it exists, then the folder holding the program). No network, no randomness, no clock: two runs produce byte-identical output.
